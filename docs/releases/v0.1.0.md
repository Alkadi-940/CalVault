First Android preview of CalVault, a working calculator with an encrypted, device-only file vault.

## Install on your phone

1. Download **CalVault-v0.1.0.apk** from this release on Android 10 or newer.
2. Open the APK. If Android asks, allow installation from your browser or file manager.
3. Open **Calculator**, create your numeric PIN, and save the separate recovery key.
4. Enter your PIN on the calculator and **hold `=`** to unlock. A normal tap calculates.

## Included

- Encrypted photos, videos, and arbitrary files; folders, search, renaming, and selection.
- In-app photo viewing and authenticated video playback with seeking.
- Verified imports, explicit export, automatic locking, and PIN-attempt delays.
- Manual encrypted backups and recovery using a separately saved recovery key.
- No accounts, advertising, analytics, cloud sync, or Internet permission.

Importing makes an encrypted copy and leaves the original in place. Remove originals separately after verifying your copies. Keep the recovery key separate from backups; uninstalling or clearing app data removes the local vault.

## Verification and preview status

The implementation passed 18 core tests, including a 2 GiB file round trip, Android 10 and Android 16 emulator flows, and Android lint. The v0.1.0 package updates the version metadata and keeps the same development signing identity as the initial alpha.

This is a development-signed preview. Physical-device coverage and independent security review remain outstanding; test with copies of files. Production signing is not configured. SHA256SUMS.txt accompanies the APK for download verification.
